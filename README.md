# MIT 6.100L Problem Set Solutions (PS1 - PS5)
## Project Overview

This repository contains the complete set of solutions and implementation files for the MIT 6.100L (Introduction to Computer Science and Programming in Python) problem sets, covering foundational concepts in computer science, algorithm design, object-oriented programming, and data manipulation.

### Table of Contents

| Problem Set | Solution File(s) | Objective |
|---|---|---|
| PS1 | ps1.py | Basic Python Programming & Financial Modeling - Implementing fundamental functions, loops, and control flow structures to model simple financial scenarios (e.g., calculating debt payoff or savings goals). |
| PS2 | ps2.py | Algorithmic Thinking & Interactive Games - Developing algorithms for iterative problems and applying techniques like bisection search to create an interactive guessing game. |
| PS3 | ps3.py | Data Structures & Word Games - Implementing the core logic, scoring, and management of word lists and hand data for an interactive word game, demonstrating proficiency with dictionaries and lists. |
| PS4 | ps4a.py, ps4b.py, ps4c.py | Object-Oriented Programming (OOP) & Cryptography - Designing classes for messages, plaintext, and encrypted data, and implementing encryption/decryption techniques (like the Vigenère cipher and one-time pads) to decode hidden stories. |
| PS5 | ps5.py | Image Processing & Steganography - Manipulating images using the PIL/NumPy libraries to simulate color blindness filters and implementing Least Significant Bit (LSB) techniques to hide and reveal secret images within other image files. |


### Key Takeaways

This project demonstrates proficiency and understanding across several critical computer science and programming concepts:

* Core Python & Control Flow: Mastery of loops, conditionals, and functions.
* Algorithmic Analysis: Implementation and efficiency analysis of search algorithms (e.g., bisection search).
* Data Structures: Effective use of lists, dictionaries, and tuples for data storage and manipulation.
* Object-Oriented Programming (OOP): Design and implementation of classes, inheritance, and encapsulation for reusable and modular code (PS4).
* Data Manipulation & Libraries: Working with external libraries (numpy, PIL) to handle complex data types like matrices and images (PS5).
* Information Theory: Practical application of cryptographic principles and data hiding techniques (LSB steganography).
